Prepare Debian 12 Netinst USB

Debian 12 (Bookworm) provides a netinst image (~700 MB) with non-free firmware for Realtek, Intel, and AMD chips out of the box.

1. Download Official Debian 12 Image

bash / curl 
# Download latest Bookworm Netinst ISO:
curl -LO https://cdimage.debian.org/debian-cd/current/amd64/iso-cd/debian-12.8.0-amd64-netinst.iso
curl -LO https://cdimage.debian.org/debian-cd/current/amd64/iso-cd/SHA256SUMS
grep debian-12.8.0-amd64-netinst.iso SHA256SUMS | sha256sum -c

2. Flash ISO to USB Drive

On macOS or Windows, write using balenaEtcher or Rufus (DD mode). Or on Linux:

bash (Linux) 
# Replace /dev/sdX with your USB drive identifier:
sudo dd if=debian-12.8.0-amd64-netinst.iso of=/dev/sdX bs=4M status=progress oflag=sync

Install Debian 12 with Btrfs Subvolumes
  1. Plug in the USB drive, power on, and press F12 / Del / F2 to boot from USB.
  2. Choose Graphical install.
  3. Set language, country, keyboard, and hostname: debian-node.
  4. Set root password and create user reen.
  5. Partitioning (Critical Step for Snapshots):
    • Select Manual Partitioning on /dev/nvme0n1.
    • Delete existing partitions.
    • Create EFI partition: 1 GB, type FAT32 / EFI System Partition, mount as /boot/efi.
    • Create Swap partition: 8 GB, type swap.
    • Allocate remaining space (~229 GB): type Btrfs, mount point /.
  6. Package Selection (Software Selection):
    • [✔] Debian desktop environment
    • [✔] XFCE (Uncheck GNOME!)
    • [✔] SSH server
    • [✔] Standard system utilities
  7. Install GRUB boot loader to UEFI drive and reboot.

Configure Snapper & GRUB Boot Rollback

This is what protects you from any rogue AI agent. Snapper takes automatic pre/post snapshots whenever packages are modified, and lets you roll back the entire OS in one command:

1. Install Snapper & grub-btrfs

bash 
sudo apt update && sudo apt install -y snapper btrfs-progs inotify-tools git

# Create Snapper config for root filesystem:
sudo snapper -c root create-config /

# Give user 'reen' permission to view snapshots:
sudo sed -i 's/ALLOW_USERS=""/ALLOW_USERS="reen"/' /etc/snapper/configs/root

# Enable automated timeline snapshots and cleanup:
sudo systemctl enable --now snapper-timeline.timer
sudo systemctl enable --now snapper-cleanup.timer

2. Enable GRUB Btrfs Menu (Boot into Past Snapshots)

bash 
# Install grub-btrfs so snapshots appear directly in the boot menu:
git clone https://github.com/Antynea/grub-btrfs.git /tmp/grub-btrfs
cd /tmp/grub-btrfs && sudo make install
sudo systemctl enable --now grub-btrfsd

ℹ How to Undo Agent Breakages in the Future:

  • From Terminal: sudo snapper list → sudo snapper rollback <number> → reboot.
  • If System Won't Boot: Select the snapshot right in the GRUB boot menu to boot into a known good state!

Configure Tailscale & Native Remote Desktop (xrdp)

Because XFCE is an X11 environment, xrdp works natively with full clipboard sharing and display resizing from the official Windows Remote Desktop / Mac Microsoft Remote Desktop client:

1. Install & Configure xrdp

sudo adduser xrdp ssl-cert

# Configure xrdp to launch XFCE:

chmod +x ~/.xsession

sudo systemctl enable --now xrdp

2. Install & Connect Tailscale

sudo systemctl enable --now tailscaled
