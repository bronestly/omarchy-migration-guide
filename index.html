⚠ Critical Notice: Single Partition Layout

Your current installation uses /dev/nvme0n1p3 for both root (/) and /home. Installing Omarchy requires formatting this drive to Btrfs. All data on the internal drive will be erased. You must copy your backup archive to your Mac (mbpr) or an external USB drive before booting the installer!

2
Prepare Omarchy USB & BIOS Settings

1. Download Official Omarchy 4.0.4 ISO

Download the official image (can be done directly on your Mac or current machine):

curl / wget 
curl -LO https://iso.omarchy.org/omarchy-4.0.4.iso
curl -LO https://iso.omarchy.org/omarchy-4.0.4.iso.sha256
sha256sum -c omarchy-4.0.4.iso.sha256

2. Flash to USB Stick

Use balenaEtcher on Mac/Windows, or write it via terminal:

bash 
# Replace /dev/sdX with your USB drive identifier
sudo dd if=omarchy-4.0.4.iso of=/dev/sdX bs=4M status=progress oflag=sync

3. Critical BIOS Settings Before Booting

⚠ Mandatory Requirements in BIOS:

  • Disable Secure Boot: Omarchy uses the Limine bootloader with custom kernel modules which requires Secure Boot to be turned OFF in BIOS.
  • Disable TPM / Intel PTT: Must be disabled or set to allow custom bootloader signatures.
  • Use a Wired / 2.4GHz Dongle Keyboard: Full-disk encryption password prompts at boot do NOT support Bluetooth keyboards. Ensure you have a wired or USB-dongle keyboard.
3
Install Omarchy Linux
  1. Insert the USB drive, turn on the PC, and press F12 / Del / F2 to select boot from USB.
  2. The Omarchy installer will boot into a sleek TUI wizard.
  3. Answer the configuration prompts:
    • Keyboard layout: Select your preferred layout.
    • Timezone: Select your local timezone.
    • Username: Enter reen.
    • Password: Enter your user password (this will also be used as the LUKS disk encryption key).
  4. Target Drive: Select your NVMe drive (/dev/nvme0n1) and choose Full-disk installation.
  5. The installer will partition Btrfs (@ and @home), install packages, and configure Limine. The entire install completes in ~1 to 2 minutes.
  6. Reboot and remove the USB drive when prompted.

Re-establish Tailscale & Base Services

Once you log into Omarchy, open a terminal (press Super + Enter for the Foot/Ghostty terminal):

1. Install Core Daemons via Pacman

bash 
sudo pacman -Syu --noconfirm docker docker-compose openssh tailscale rsync chezmoi git

# Enable and start services
sudo systemctl enable --now docker
sudo systemctl enable --now sshd
sudo systemctl enable --now tailscaled

# Add user to docker group
sudo usermod -aG docker $USER

2. Reconnect Tailscale

bash 
# Reconnect node and enable Tailscale SSH
sudo tailscale up --ssh --operator=reen

# Check connection to your Mac
tailscale ping 100.81.195.25

3. Restore Tailscale Dev Publishing Script

bash 
# Transfer backup from Mac
scp rene@100.81.195.25:~/omarchy-migration-backup-*.tar.gz ~/
tar -xzvf ~/omarchy-migration-backup-*.tar.gz

# Put dev publish script back in ~/.local/bin/
mkdir -p ~/.local/bin
cp omarchy-migration-backup-*/networking/tailscale-dev-publish.py ~/.local/bin/
chmod +x ~/.local/bin/tailscale-dev-publish.py

# Add to Omarchy autostart
echo 'o.launch_on_start("python3 /home/reen/.local/bin/tailscale-dev-publish.py")' >> ~/.config/hypr/autostart.lua

Remote Desktop & Zoom Call Recording

Because Omarchy runs pure Wayland and Hyprland, the highest performance way to remote desktop in from your Mac/Windows to run browsers and record calls is Sunshine + Moonlight:

1. Install Sunshine on Omarchy

bash

Open https://localhost:47990 in Chromium to set your PIN, then open Moonlight on your Mac/Windows laptop to connect at 60 FPS with stereo loopback audio.

2. Recording Zoom Calls & Audio

  • Hotkey Recording: Press Alt + Print Screen to select any browser window and start high-fps recording with audio straight to ~/Videos/Recordings/.
  • Headless Recording: Even if you close your remote desktop session, run this in the background:
