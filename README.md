## Quick Reference

### 1. Run Pre-Migration Backup on Pop!_OS
```bash
# Execute the automated backup script
sudo ./backup-popos.sh

# Transfer the archive to your Mac (mbpr) over Tailscale
ARCHIVE=$(ls -t ~/omarchy-migration-backup-*.tar.gz | head -1)
scp "$ARCHIVE" rene@100.81.195.25:~/

# Sync project repos to Mac
rsync -avhP ~/Projects ~/sparkyfitness ~/OpnForm rene@100.81.195.25:~/pop-full-backup/
```

### 2. Download Omarchy 4.0.4 ISO
- ISO: `https://iso.omarchy.org/omarchy-4.0.4.iso`
- SHA256: `https://iso.omarchy.org/omarchy-4.0.4.iso.sha256`
- Flash to USB using BalenaEtcher or `caligula`

### 3. BIOS Requirements
- **Disable Secure Boot** (Mandatory for Omarchy / Limine)
- **Disable TPM / Intel PTT**
- **Use a wired / 2.4GHz dongle keyboard** (Bluetooth keyboards do not work at LUKS boot prompt)

### 4. Post-Install Core Setup
```bash
sudo pacman -Syu --noconfirm docker docker-compose openssh tailscale rsync chezmoi git sunshine
sudo systemctl enable --now docker sshd tailscaled
sudo usermod -aG docker $USER

# Reconnect to Tailscale with same operator
sudo tailscale up --ssh --operator=reen
```

### 5. Restore Dev Publishing & SparkyFitness Serve
```bash
# Put dev publish script back in ~/.local/bin/
cp omarchy-migration-backup-*/networking/tailscale-dev-publish.py ~/.local/bin/
chmod +x ~/.local/bin/tailscale-dev-publish.py

# Add to Omarchy autostart
echo 'o.launch_on_start("python3 /home/reen/.local/bin/tailscale-dev-publish.py")' >> ~/.config/hypr/autostart.lua

# Restore SparkyFitness Tailscale Serve unit
sudo cp omarchy-migration-backup-*/networking/sparkyfitness-tailscale-serve.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now sparkyfitness-tailscale-serve.service
```

### 6. Remote Desktop & Recording (Zoom / Browser)
- Run **Sunshine** on Omarchy (`systemctl --user enable --now sunshine`)
- Connect from your Mac using **Moonlight** for 60fps low-latency browsing with full PipeWire audio
- Record any call or browser window on demand via `Alt + Print Screen` or via CLI:
  ```bash
  wl-screenrec --audio --filename ~/zoom-call-$(date +%F_%H-%M).mp4
  ```
